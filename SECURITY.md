# Security Policy

## Supported versions

NEXUS Monitor is currently pre-release software. Security fixes are applied to the latest code on the `main` branch until versioned releases begin.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub private vulnerability reporting from the repository's Security tab after the public repository enables it.

Include the affected component, impact, reproduction steps, and any suggested mitigation. Remove credentials and sensitive machine information from reports. Maintainers will acknowledge a complete report as soon as practical and coordinate disclosure after a fix is available.

## Scope

Agent authentication, data minimization, ingestion validation, and network exposure are security boundaries. Development defaults are not production deployment guidance unless explicitly documented as such.
